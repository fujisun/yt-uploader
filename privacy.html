プライバシーポリシー

yt-uploader（以下「本ツール」）は、管理者が自分のYouTubeチャンネルへ動画を投稿するための個人用ツールです。

  • 本ツールが使うのは、YouTube Data API で許可された範囲（動画のアップロードと動画情報の編集）だけです。
  • 取得した情報は管理者のPCの中だけで使い、外部のサーバーへ送ったり、第三者に渡したりしません。
  • 認証情報は管理者のPCにだけ保存します。
  • Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセス権を取り消せます。
  • 本ツールは YouTube API サービスを利用しています。YouTube 利用規約および Google プライバシーポリシーも適用されます。

お問い合わせは、本ツールの GitHub リポジトリ からお願いします。
